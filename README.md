## 🚀 快速开始 (Quick Start)

### 1. 克隆仓库

```bash
git clone https://github.com/zhaorui-bi/DVAM-Group-1-Final-Project.git
```

### 2. 安装依赖

```bash
pip install uv
uv pip install -r requirements.txt
```

### 3. 数据预处理与分析

具体预处理结果和可视化结果在Jupyter Notebook当中

